# MacSweep v1.1.4

## GUI scope

MacSweep is a native macOS 26 Tahoe app with Smart Care, Browser Cleanup, Large & Old Files, developer cleanup, storage review, uninstallation, maintenance, and optional AI analysis. This release exposes Browser Cleanup and Large & Old Files in navigation, adds cancellable developer scans, and makes partial scan failures visible. Cleanup requires review and live safety checks; supported file cleanup moves targets to Trash. Conversation archives remain protected user data. Results distinguish estimated target allocation, performed actions, and observed volume changes; Trash moves and APFS allocation are not claims of physical space recovered.

The Homebrew cask installs the signed, notarized GUI and the CLI formula. The app supports signed Sparkle updates. Full Disk Access is optional for launching; protected sources can report partial results until the user grants it.

## Deferred features

The iOS companion, Mac–iOS/cloud sync, extensions manager, paid licensing, App Store distribution, and automatic background deletion are deferred. Large-file, duplicate, photo, uninstaller-leftover, and developer-project findings require manual review. Optional AI analysis requires a user-supplied provider key; deterministic scanning works without AI. This release does not include later work merged after the v1.1.4 tag.

## Changes

- Protect conversation archives and narrowly allow supported Mail attachments while retaining databases and symlinks.
- Preserve filesystem/tool failures across GUI, CLI, Smart Care, and scheduled scans.
- Discover supported hidden build artifacts/worktrees and include hidden folder data in bounded size estimates.
- Report malware scanning as a persistence audit with explicit coverage limits.
